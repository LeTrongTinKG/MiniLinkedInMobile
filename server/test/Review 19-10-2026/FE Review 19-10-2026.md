## Vấn đề 1 — Đọc sai cấu trúc response lỗi từ BE

**File:** `app/lib/core/network/dio_client.dart` — dòng 124–125

Khi BE trả về lỗi, format luôn là:
```json
{ "error": { "code": "EMAIL_ALREADY_EXISTS", "message": "Email này đã được sử dụng" } }
```

Nhưng DioClient đang đọc theo:
```dart
final errorCode = body?['errorCode'] ...  // ← tìm field 'errorCode' ở tầng ngoài
final message = body?['message'] ...      // ← tìm field 'message' ở tầng ngoài
```

Kết quả cả hai đều `null` → fallback về `'UNKNOWN_ERROR'` và `'Đã có lỗi xảy ra'`.

**Hành vi:** Mọi lỗi từ BE (email trùng, sai mật khẩu, tài khoản bị khóa...) đều hiển thị cùng 1 dòng chữ "Đã có lỗi xảy ra" — user không biết tại sao.

**Hướng fix:**
```dart
final errorBody = body?['error'] as Map<String, dynamic>?;
final errorCode = errorBody?['code'] as String? ?? 'UNKNOWN_ERROR';
final message = errorBody?['message'] as String? ?? 'Đã có lỗi xảy ra';
```

## Vấn đề 2 — baseUrl dùng localhost không chạy được trên Android Emulator

**File:** `app/lib/core/config/app_config.dart` — dòng 9

`baseUrl` đang là `http://localhost:5000/api/v1`. Trên Android Emulator, `localhost` trỏ vào chính máy ảo, không phải máy tính host → kết nối thất bại hoàn toàn.

**Hành vi:** Ai chạy app trên emulator sẽ bị lỗi "Không thể kết nối đến máy chủ" ngay từ màn đầu tiên dù server đang chạy bình thường.

**Hướng fix:** Đổi thành `http://10.0.2.2:5000/api/v1` cho Android Emulator. Điện thoại thật thì dùng IP LAN hoặc `adb reverse tcp:5000 tcp:5000`. README đã có hướng dẫn, chỉ cần đổi giá trị default.

## Vấn đề 3 — Mất mạng khi mở app → bị kick ra màn đăng nhập

**File:** `app/lib/features/auth/presentation/providers/auth_provider.dart` — dòng 67–70

`checkAuth()` gọi `GET /auth/me` khi app khởi động. Nếu không có internet, lỗi `NetworkException` được catch chung với `UnauthorizedException` và xử lý như nhau: xóa user, chuyển về màn login.

**Hành vi:** User đang đăng nhập, tắt wifi rồi mở lại app → bị văng ra màn đăng nhập dù chưa đăng xuất. Đặc biệt tệ trên mobile vì mạng hay bị gián đoạn.

**Hướng fix:** Tách riêm 2 trường hợp: `UnauthorizedException` → unauthenticated, `NetworkException` → giữ nguyên trạng thái cũ hoặc hiển thị màn "Không có mạng, thử lại".
