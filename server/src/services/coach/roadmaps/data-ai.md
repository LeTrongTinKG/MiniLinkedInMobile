# Lộ trình Dữ liệu và AI (Python)

Bắt đầu từ Phân tích dữ liệu (Data Analyst), vì đây là công việc đầu tiên thực tế nhất. AI Engineer thường là công việc thứ hai, sau khi đã có nền dữ liệu hoặc backend.
Dành cho sinh viên học 1–2 giờ mỗi ngày. Tổng khoảng 21 tuần (5 tháng).
Tên skill viết đúng như từ điển `skillsDictionary.js`.

| Bước | Skill cần có | Học gì | Bằng chứng nên có | Thời gian gợi ý |
|---|---|---|---|---|
| 1. Python và Git | `python`, `git` | Kiểu dữ liệu, hàm, file, thư viện chuẩn, môi trường ảo, pip. | Repo bài tập Python có Python từ 10% trở lên, commit đều. | 3 tuần |
| 2. SQL và bảng tính | `sql`, `excel` | SELECT, JOIN, GROUP BY, hàm cửa sổ; làm sạch dữ liệu trong Excel. | Repo các câu SQL trả lời câu hỏi trên một bộ dữ liệu công khai. | 3 tuần |
| 3. Xử lý dữ liệu | `pandas` | Đọc, làm sạch, gộp, nhóm dữ liệu; thống kê mô tả. | Notebook phân tích một bộ dữ liệu thật, khai báo `pandas` trong `requirements.txt`. | 4 tuần |
| 4. Trực quan hóa và báo cáo | `tableau` | Biểu đồ đúng loại, dashboard; viết kết luận cho người không làm kỹ thuật. | 2–3 bài phân tích có dashboard và một quyết định đề xuất. | 2 tuần |
| 5. Học máy cơ bản | `machine learning` | Hồi quy, phân loại, chia tập train/test, đánh giá mô hình trung thực; scikit-learn. | Một mô hình đã huấn luyện và đánh giá, README ghi rõ số đo. | 5 tuần |
| 6. Đưa AI vào sản phẩm | `fastapi`, `huggingface` | Xây API bằng FastAPI, gọi mô hình có sẵn, đo chất lượng câu trả lời. | API nhận câu hỏi, gọi mô hình, trả kết quả có kiểm tra. | 4 tuần |

## Sẵn sàng đi làm khi

- Có 2–3 bài phân tích trên dữ liệu thật, mỗi bài kết thúc bằng một quyết định người đọc làm được.
- Cho vị trí AI: có một sản phẩm nhỏ dùng mô hình, có bộ câu đo chất lượng.
