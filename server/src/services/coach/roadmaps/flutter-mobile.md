# Lộ trình Mobile (Flutter)

Dành cho sinh viên học 1–2 giờ mỗi ngày. Tổng khoảng 17 tuần (4–5 tháng).
Tên skill viết đúng như từ điển `skillsDictionary.js`, để chatbot so được với skill của người dùng.

| Bước | Skill cần có | Học gì | Bằng chứng nên có | Thời gian gợi ý |
|---|---|---|---|---|
| 1. Nền tảng | `git`, `dart` | Cài Flutter SDK, Git, IDE, máy ảo. Dart: biến, hàm, lớp, null safety, async/await. | Một repo GitHub của bạn có Dart từ 10% trở lên, commit trải nhiều ngày. | 2 tuần |
| 2. Widget và bố cục | `flutter` | Stateless/Stateful widget, Row, Column, Stack, ListView, theme. | App máy tính hoặc BMI trên GitHub, có `pubspec.yaml`. | 3 tuần |
| 3. Điều hướng, form, trạng thái | `state management` | Điều hướng, truyền dữ liệu giữa màn, form và kiểm tra nhập, setState, Provider. | App to-do có lưu dữ liệu, khai báo `provider` trong `pubspec.yaml`. | 3 tuần |
| 4. Dữ liệu thật | `rest api`, `firebase` | Gọi HTTP, JSON và model, xử lý lúc tải và lúc lỗi; lưu trữ cục bộ; Firebase. | App thời tiết hoặc ghi chú gọi API thật. | 3 tuần |
| 5. Kiến trúc và trạng thái nâng cao | `bloc` hoặc `state management` (Riverpod) | Chọn một: Bloc/Cubit hoặc Riverpod, học kỹ. Tách lớp theo MVVM. | Một app chia thư mục rõ ràng, dùng `flutter_bloc` hoặc `riverpod`. | 3 tuần |
| 6. Kiểm thử và phát hành | `ci/cd` | Unit test, widget test, DevTools; build Android/iOS; GitHub Actions. | Repo có thư mục `test/` và file workflow CI; một bản build phát hành. | 3 tuần |

## Sẵn sàng đi làm khi

- Có 2–3 app hoàn chỉnh trên GitHub, README rõ ràng.
- Giải thích sâu được một cách quản lý trạng thái (Provider, Bloc hoặc Riverpod).
