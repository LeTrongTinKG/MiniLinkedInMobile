# Lộ trình Frontend (React)

Dành cho sinh viên học 1–2 giờ mỗi ngày. Tổng khoảng 20 tuần (5 tháng).
Tên skill viết đúng như từ điển `skillsDictionary.js`.

| Bước | Skill cần có | Học gì | Bằng chứng nên có | Thời gian gợi ý |
|---|---|---|---|---|
| 1. Web cơ bản | `html`, `css`, `git` | Internet và HTTP hoạt động thế nào, HTML ngữ nghĩa, form, khả năng truy cập; CSS bố cục, responsive. | Trang cá nhân tĩnh trên GitHub Pages. | 3 tuần |
| 2. JavaScript | `javascript` | Cú pháp, DOM, sự kiện, Fetch API, async/await, module. | Trang gọi một API công khai và hiển thị kết quả. | 4 tuần |
| 3. React | `react` | Component dạng hàm, JSX, props và state, danh sách và key, `useState`, `useEffect`, custom hook, router. | App thẻ học hoặc app trắc nghiệm, khai báo `react` trong `package.json`. | 4 tuần |
| 4. Dữ liệu và trạng thái | `rest api`, `redux` hoặc `state management` | Gọi API, xử lý lúc tải và lúc lỗi, form; Context, Redux Toolkit hoặc Zustand. | App thời tiết hoặc tìm repo GitHub dùng API thật. | 3 tuần |
| 5. TypeScript và giao diện | `typescript`, `tailwind` | Kiểu cho props và API, Zod; Tailwind CSS; công cụ build Vite. | Repo có `tsconfig.json`, dùng Tailwind. | 3 tuần |
| 6. Kiểm thử và phát hành | `jest`, `ci/cd` | Vitest/Jest, React Testing Library; Lighthouse; triển khai tự động. | Repo có test chạy trong GitHub Actions và link bản đã triển khai. | 3 tuần |

## Sẵn sàng đi làm khi

- Có 2–3 dự án React đã triển khai, gọi API thật, chạy được trên điện thoại.
- Giải thích được vòng đời render và khi nào cần `useEffect`.

## Thị trường

- TopDev: gần 80% công ty ở Việt Nam tuyển JavaScript; nhiều chương trình fresher dạy ReactJS (ví dụ FPT Software tuyển Fresher Java & ReactJS năm 2026).
