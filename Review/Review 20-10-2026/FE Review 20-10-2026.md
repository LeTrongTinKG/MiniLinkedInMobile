## Phân tích vấn đề F5 / mở lại app bị kick ra login

### Nguyên nhân

F5 trên Chrome mô phỏng đúng hành vi đóng và mở lại app vì toàn bộ Dart state trong RAM bị xóa, chỉ còn `flutter_secure_storage` (localStorage trên web) giữ token.

**BE không có lỗi.** Từ phía BE:
- Access token còn hạn → `GET /auth/me` trả 200 ✓
- Access token hết hạn → trả 401 → FE gọi `POST /auth/refresh` → BE trả token mới 200 ✓

**Lỗi nằm hoàn toàn ở FE** — `auth_provider.dart` gom `NetworkException` vào cùng nhánh với `UnauthorizedException`:

```dart
// auth_provider.dart dòng 64–73
on UnauthorizedException {
  _status = AuthStatus.unauthenticated; // token thực sự hết hạn/không hợp lệ
}
on AppException {
  // ← NetworkException cũng rơi vào đây
  _status = AuthStatus.unauthenticated; // bị xử lý như chưa đăng nhập
}
```

Kết quả: bất kỳ lỗi kết nối nào khi mở app (server chưa kịp khởi động, mạng yếu, emulator dùng localhost không kết nối được) đều bị hiểu là "chưa đăng nhập" → kick về màn login dù token vẫn còn hạn.

## Vấn đề cần sửa

### 1 — Tách NetworkException ra khỏi luồng unauthenticated

**File:** `app/lib/features/auth/presentation/providers/auth_provider.dart` — hàm `checkAuth()`

**Hướng fix:**
```dart
Future<void> checkAuth() async {
  _setLoading();
  try {
    _currentUser = await _getMeUseCase();
    _status = AuthStatus.authenticated;
    _errorMessage = null;
  } on UnauthorizedException {
    // Token thực sự không hợp lệ hoặc hết hạn và không refresh được → về login
    _status = AuthStatus.unauthenticated;
    _currentUser = null;
  } on NetworkException {
    // Mất mạng khi mở app → KHÔNG kick ra, giữ nguyên trạng thái để thử lại
    _status = AuthStatus.unauthenticated;
    _errorMessage = 'Không thể kết nối máy chủ. Vui lòng kiểm tra mạng và thử lại.';
    _currentUser = null;
  } on AppException catch (e) {
    _status = AuthStatus.unauthenticated;
    _errorMessage = e.message;
    _currentUser = null;
  } finally {
    notifyListeners();
  }
}
```

### 2 — Parse sai cấu trúc response lỗi từ BE

**File:** `app/lib/core/network/dio_client.dart` — dòng 124–125

Hiện tại:
```dart
final errorCode = body?['errorCode'] as String? ?? 'UNKNOWN_ERROR';
final message = body?['message'] as String? ?? 'Đã có lỗi xảy ra';
```

BE trả về format:
```json
{ "error": { "code": "EMAIL_ALREADY_EXISTS", "message": "Email này đã được sử dụng" } }
```

**Hướng fix:**
```dart
final errorBody = body?['error'] as Map<String, dynamic>?;
final errorCode = errorBody?['code'] as String? ?? 'UNKNOWN_ERROR';
final message = errorBody?['message'] as String? ?? 'Đã có lỗi xảy ra';
```
